CALarm requires iOS 26 or later for AlarmKit. Alarms ring only on a physical device; the iOS Simulator cannot ring AlarmKit alarms.

There is no CALarm account and no server. The app reads the on-device calendar (EventKit) and everything stays on the device.

To test:
1. Grant Calendar access when prompted.
2. Add an event to the device calendar a few minutes from now if none is upcoming.
3. Tap the square next to the event to arm its alarm. CALarm asks for Alarms permission the first time.
4. The countdown appears on the Lock Screen and in the Dynamic Island, and the alarm rings before the event.
Settings → Test alarm rings a sample alarm in about 16 seconds.

Optional Google Calendar connection: Settings → Calendars → Connect Google Calendar. This is not a login to CALarm and is not needed for review. It is a read-only (calendar.readonly) connection that lets the app read the user's Google calendars directly from the device. Because CALarm has no user accounts, Sign in with Apple does not apply (Guideline 4.8).

By default no event has an alarm. Alarms are scheduled only for events the user arms, or for new events once the user picks a default alarm in Settings → Alarms.
